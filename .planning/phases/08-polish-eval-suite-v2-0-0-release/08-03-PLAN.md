## Terminology (B1 — canonical vs raw tool count)

Throughout this MIGRATION guide and the rest of Phase 8 documentation, two distinct counts apply to v2.0.0's tool surface:

- **Raw `tools/list` length = 37.** This is the MCP-protocol-observable response length. All 23 v1 tool names + 14 net-new v2 tools are still in `tools/list`. The 5 list-style tools promoted to Resources (REL-08) **remain in the array** with the suffix " DEPRECATED since v2.0.0 — prefer MCP Resource `<uri>` for agent discovery. The tool remains callable through v2.x; removal scheduled for v3.0.0." in their `description` field.
- **Canonical (non-deprecated) tool count = 32.** This is the surface agents are encouraged to discover and use; the 5 deprecated entries are an additive transition path, not the canonical surface.
- **Resources surface = 10 entries.** 5 pre-existing (memory-sinks, memory-stats, briefs, contracts, contract-verbs) + 5 new (vaults, models, recent, stats, backlinks).

When the ROADMAP / README / CHANGELOG / this doc says "tool surface inventory ≤32 tools (with MCP Resources promotion)", that refers to the **canonical** count. The raw `tools/list` response in v2.0.0 returns 37 entries — by design, per D-03 (additive then deprecating).
