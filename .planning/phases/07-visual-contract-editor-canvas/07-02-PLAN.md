Define the `.contract` JSON document schema and the pure-TS round-trip codec that converts between `.contract` and Phase 6 YAML. The codec is the shared substrate the editor view (07-05) and the round-trip acceptance tests (07-06) both depend on. No Obsidian imports — pure data layer.

Purpose: Lock the file format contract so subsequent plans can build UI and tests against a stable type.
Output: A Zod `ContractDocumentSchema` (server-side, BYREF the Phase 6 ContractFileSchema), and a plugin-side codec with three pure modules (`contract-codec`, `canonicalize`, `editor-state-comment`) plus co-located tests.
</objective>
