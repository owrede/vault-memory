<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `.contract` JSON file loaded by Obsidian | Untrusted input from disk; may have been authored by hand or another tool |
| Svelte Flow rendering arbitrary node positions | Position values come from the file's `editor.nodes` array |
| Palette drag-drop event payload | HTML5 drag-and-drop carries a verb name; must be matched against the closed enum |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05-01 | Tampering | `.contract` file load | mitigate | `ContractDocumentSchema.parse` validates before mount; invalid files show an error pane and do NOT mount the editor |
| T-07-05-02 | Tampering | Palette drag-drop verb | mitigate | The dropped value is checked against `BASELINE_VERBS` (closed enum) ∪ peer-MCP verbs ∪ `"literal"`; unknown values are dropped silently with a `Notice` |
| T-07-05-03 | Denial of Service | Canvas pan + zoom triggers file save | mitigate | RESEARCH Pitfall 7: viewport-only changes are debounced (500ms) AND do not commit unless piggy-backed on another save; saves fire only on user-initiated mutations (drag, add, edit) |
</threat_model>
