## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Schema migration | New SQL DDL + UPDATE statement; runs once per DB at version bump. SQLite transaction (database.ts:99) wraps the migration runner — rollback on failure is the existing safety net. |
| User vault name → doc_uri prefix | Vault names come from `config.toml`. They're already used as filesystem paths in `~/.vault-memory/dbs/<name>.db` (existing trust); using them in doc_uri prefixes is no new trust surface. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-01 | Tampering | Backfill UPDATE statement | mitigate | Uses parameterized `@prefix` via better-sqlite3 prepared statement — no SQL injection surface. The `path` column is concatenated via SQL `||` operator, not string-interp into the query. |
| T-01-02-02 | Information disclosure | doc_uri stores vault-relative path verbatim | accept | Same exposure as existing `notes.path` column. No PII not already in v1. |
| T-01-02-03 | Tampering | Migration idempotency | mitigate | `WHERE doc_uri IS NULL` clause + the migration version gate in database.ts:99 ensure the backfill cannot corrupt existing values. Test 4 + Test 6 assert this. |
| T-01-02-04 | Denial of service | Long backfill on large vaults | accept | A single UPDATE with WHERE clause on an indexed column scales linearly. Atlas fixture (~75 notes) backfills in <100ms (RESEARCH A8). User vaults of 10k notes would take ~1-2s — acceptable one-time cost. SQLite transaction means partial failure rolls back, no half-state. |
| T-01-02-05 | Tampering | doc_uri does not match SourceConnector handle | mitigate | Test 8 asserts every backfilled doc_uri passes `parseDocId` from src/adapters/registry.ts — the regex is the contract. |

**Net security delta:** Neutral. Migration adds a new column with the same data-class exposure as the existing `path` column. No new attack surface; no existing validator/sanitizer touched.
