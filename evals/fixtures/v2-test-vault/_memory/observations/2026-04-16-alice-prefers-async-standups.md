# Alice prefers async standups

Alice has explicitly stated a preference for async written updates over live
standups. The "Monday weekly written" Linear thread is her invention — every
project lead writes a 200-word update by Sunday EOD; she reads them Monday
morning; the team converges via async comments rather than a meeting.

Implication for scheduling: do not propose live recurring meetings with Alice
unless the discussion is genuinely synchronous (decision, debate, customer
call). Default to written threads.
