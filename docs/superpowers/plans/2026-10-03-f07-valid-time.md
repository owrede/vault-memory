# F07 Fachliche Gültigkeitszeit und historische Abfragen Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wann eine Aussage gilt vom Zeitpunkt ihrer Beobachtung unterscheiden.

**Architecture:** UTC-valid_from/valid_to werden optional auf dokument- und aussagenbezogener Ebene validiert. Die Suche filtert vor Ranking/Limit, standardmäßig für den aktuellen Zeitpunkt; historische v2-Anfragen geben as_of explizit an. Supersede bleibt getrennt von Gültigkeit.

**Tech Stack:** TypeScript, Vitest, SQLite, bestehende Adapter-/Controllerarchitektur.

**Spec:** `docs/superpowers/specs/2026-10-03-basic-memory-inspired-design.md`, F07; der Feature-Vertrag unten konkretisiert dessen Lieferung.

**Status:** Geplant. Tests und Kommandos dieses Plans sind Abnahmevorgaben und wurden noch nicht als Implementierungsnachweis ausgeführt.

**Voraussetzungen:** F04, F06.

```ts
import {expect, it} from "vitest";
import {isValidAt} from "./valid-time.js";
it("uses an inclusive start and exclusive end", () => {
  const range={valid_from:"2026-01-01T00:00:00Z",valid_to:"2026-02-01T00:00:00Z"};
  expect(isValidAt(range,"2026-01-01T00:00:00Z")).toBe(true);
  expect(isValidAt(range,"2026-02-01T00:00:00Z")).toBe(false);
});
```

```ts
const t=Date.parse(asOf);
if (!Number.isFinite(t)) throw new RangeError("invalid as_of");
return (validity.valid_from == null || Date.parse(validity.valid_from) <= t)
  && (validity.valid_to == null || t < Date.parse(validity.valid_to));
```
